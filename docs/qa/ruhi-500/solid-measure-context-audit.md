# Solid measurement context audit

The 25 original workbook rows have fixed, dimensionless native-scene fixtures and explicit expected formulas. That evidence does not certify unrestricted solid-measurement dialogue.

Remaining requirements:

- Stable solid identity: current native Solid records lack IDs. The annotation detects changed list size, reference types and unreferenced objects conservatively. Reordering same-type referenced solids is indistinguishable from dimension edits; multi-object stable IDs require a coordinated model/codec/remapping migration.
- Unit parsing/conversion: annotations use generic units or the existing explicit measurement-unit metadata. Text unit suffixes and mixed-unit conversion are not independently certified. Do not interpret the workbook checks as unit-conversion proof.
- Broader solids: original formulas cover boxes, spheres, hemispheres, right circular cones/cylinders, and pyramid base-area volume. Euler/topology uses a whitelist of closed native convex polyhedra. Arbitrary imported or nonconvex solids need separate manifold/convexity and orientation checks.
- Full workbook clarification/suggestion policies: missing numeric dimensions and selected-object ambiguity are tested, including pending restore, numeric replies, stale answers and cancellation. Every alternate phrasing and all cross-intent/context transitions remain incomplete.
- Length/area/volume drawing placement uses the native object and camera transforms. Very large dimensions outside the visible viewport do not imply automatic framing; scene camera changes remain explicit user actions.

Existing read-only scene measurement questions preserve the established no-undo-entry contract. Literal measurement references are reversible annotation transactions. Neither path creates physical scene solids or learns numeric answers from seed rows.
