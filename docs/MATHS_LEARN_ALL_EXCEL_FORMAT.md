# Maths Learn All Excel Format

Use one row per lesson subtopic.

Required columns:

| Column | Example | Notes |
| --- | --- | --- |
| Class | Class 6 | Use Class 1 through Class 12, UG, PG, or a consistent label. |
| Chapter | Fractions | Chapter or unit name. |
| Subtopic | Equivalent Fractions | Smallest lesson unit shown in the app. |
| Introduction | Fractions describe equal parts of a whole. | Short learner-friendly opening. |
| Detailed Explanation | Equivalent fractions have the same value... | Standard explanation for average learners. |
| Realtime examples | Sharing pizza; measuring half a litre. | Separate examples with semicolons or line breaks. |

Optional personalization columns:

| Column | Purpose |
| --- | --- |
| Simplified Explanation | Step-by-step version for foundational or slow-paced learners. |
| Advanced Explanation | Deeper reasoning, proofs, edge cases, or enrichment for advanced learners. |
| Practice Prompt | Revision or self-check prompt for the lesson. |

Recommended row size:

- `Introduction`: 40-120 words
- `Detailed Explanation`: 250-600 words
- `Simplified Explanation`: 150-350 words
- `Advanced Explanation`: 200-500 words
- `Realtime examples`: 3-8 examples
- `Practice Prompt`: 1-5 questions or tasks
