# Calculus and Advanced Mathematics Phase 6 — Vector Workflows

Phase 6 exposes the remaining API-only vector-calculus capabilities through the unified Solver.

| Workflow | Evidence shown |
|---|---|
| Lagrange constrained extrema | Critical points, objective values, constraint and stationarity residuals |
| Scalar line integral | Arc-length parameterization, orientation and refinement error |
| Work integral | Oriented curve substitution and refinement error |
| Surface flux | Explicit `r_u cross r_v` orientation and sampling certificate |
| Green theorem | Boundary circulation versus interior planar curl |
| Gauss theorem | Outward box flux versus volume divergence |
| Stokes theorem | Boundary circulation versus oriented surface curl |

All workflows are searchable in the Solver calculator catalogue and produce structured steps, method rationale and numerical verification status.
