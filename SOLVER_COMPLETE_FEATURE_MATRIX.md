# Solver Complete Feature Matrix

| Capability | Status | Notes |
|---|---|---|
| Keyboard input and cursor editing | Supported | Reuses the existing keyboard |
| Typed parser, AST, exact rationals | Supported | Fail-closed syntax handling |
| Arithmetic and core algebra | Supported | Structured steps and verification |
| Advanced algebra and functions | Partial | See final limitations |
| Trigonometry and coordinate geometry | Supported subset | Exact supported angles and commands |
| Matrices and number theory | Supported subset | Validated command forms only |
| Calculus and complex numbers | Supported subset | Phase 3 command matrix applies |
| Four explanation profiles | Supported | Same transformation, adapted language |
| Alternative methods | Supported where registered | No invented alternatives |
| Visual explanations | Supported where a valid spec exists | Symbolic verification remains primary |
| Six-level hint mode | Supported | Only level six reveals the next step |
| Next-step tutor | Supported | Exact, equivalent, alternative, and invalid paths |
| Ten practice modes | Supported | Every shown problem is solved and verified first |
| Structural difficulty estimate | Supported | Not based on number size alone |
| Local mastery estimate | Supported | Aggregate and explicitly approximate |
| Solver learning-data deletion | Supported | Separate Solver preference store |
| Calculator catalogue | Supported subset | Every active preset passes central-engine tests |
| Future recognized-text adapter | Prepared, inactive | No producer connected |
| Remote solving or runtime downloads | Not used | Fully offline |

## Deferred Catalogue Entries

Partial fractions, inverse functions, intercepts, triangle solving, trig identity
simplification, trig equations, tangent/normal workflows, differential equations,
eigenvalues, and sigma evaluation remain hidden until the shared engine verifies
their starter expressions end to end.
