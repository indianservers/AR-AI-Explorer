Each entry contains a symbolic derivation, visual interpretation, conditions,
worked example and an independent verification description.

## Safety rules

- Every spec links to one or more real solution step IDs.
- Every spec has an accessibility description.
- Undefined graph samples are never joined as finite points.
- Visual verification supplements symbolic verification.
- Unsupported problems receive no visual.
